# CAST-MARL — 可复现实验材料

论文的代码、配置与逐种子实验记录

> **CAST-MARL: An Engineering Framework for Safety-Constrained Cooperative
> Multi-UAV Coverage Planning**
> 冯素慧、李琳、张奇志
> 稿件编号 Access-2026-39960，*IEEE Access*（重投）

本仓库是论文的独立核验材料，包含完整实验源码、每一次报告实验所用的确切配置、
每张表格背后的逐种子与逐回合记录，以及一条命令即可从零复现全部运行的驱动脚本。

---

## 为什么建立这个仓库

初次投稿时实验代码是作为 ZIP 附件提交的。审稿人指出：这种规模的实验流程无法通过
附件核验，建议提供公开仓库。本仓库即为回应。同时，它也记录了准备重投期间所做的
两处修正。

## 目录结构

```
experimental_runs/
  reproducibility/     实验源码与基准模块
  *.pth                两个存档检查点

archived_configs/      各地形的原始配置（逐字沿用）

```

## 运行环境

Python 3.8 及以上，依赖 `numpy`、`scipy`、`matplotlib`、`torch`。

**不需要 GPU。** 模型仅 44.4 万参数，峰值显存约 99 MB，计算瓶颈在仿真（CPU），
因此**核数远比显卡重要**。论文中的全部结果均在纯 CPU 容器上复现。

```bash
pip install -r requirements.txt
python scripts/bundle_paths.py     # 自检：打印全部解析后的路径
```

## 复现方式

```bash
bash run_all.sh                    # 全部阶段，并行数 = 核数
STAGES=0 bash run_all.sh           # 只跑协议自检（约 2 分钟）
WORKERS=16 bash run_all.sh         # 指定并行数
```

| 阶段 | 内容 |
|---|---|
| 0 | 环境检查 + 对已发表数字的协议自检 |
| 1 | 受控地形基准与组件消融（5 个种子） |
| 2 | 空可行集统计与阈值扫描 |
| 3 | 滤波器计时分布（须在空闲机器上运行） |
| 4 | 汇总为论文表格 |

阶段 1 是主要开销：3 地形 × 5 种子 × 9 个模型 = **135 个训练作业**。每个作业在
独立进程中训练单个模型，因此所有模型从相同的种子状态出发，同时能充分使用多核机器。

### 阶段 0 是真实的校验，不是形式

`scripts/_validate_protocol.py` 会重跑论文中 *Raw A\*（无滤波器）* 那一行所用的协议，
并把覆盖率、冲突率、路径长度与已发表数值比较，可复现到 5 位有效数字：

```
coverage  99.50529 +- 1.16123   对比已发表  99.505 +- 1.161     偏差 0.000%
conflict  0.01025 +- 0.01928    对比已发表  0.01025 +- 0.01928  偏差 0.035%
path      20884.66659 +- 4264.67166  对比已发表 20884.7 +- 4264.7  偏差 0.000%
轨迹重算自校验：max |sim - recomputed| = 0.000e+00  通过
```

**若此项不通过，后续阶段的结果不可信。**

## 本代码包含的两处修正

1. **评估配置。** 原脚本中，地形基准表与组件消融表背后的评估调用并未使用这两张表
   所标注的地形：基准中的每个方法都在同一个 `simple` 环境中评估，每个消融变体都在
   `dynamic_users` 环境中评估，因此地形标签只通过训练权重进入这两张表；同一批调用
   也没有传入评估种子。受控驱动修正了这一点：训练与评估使用同一地形，评估种子固定
   并记录，且使用 5 个训练种子。

2. **注意力消融。** 原来的注意力变体没有在保留 transformer 骨架的前提下只移除注意力
   运算，因此两行消融无法隔离出各自的因素。现在的变体保留四路流编码器、两个 pre-norm
   块、前馈子层以及完整的 444,118 参数预算，只把多头注意力替换为对 agent 轴的无参均值
   聚合。已验证的参数量：完整模型 444,118 · 无注意力 444,118 · 无 Transformer 54,279。

## 数据与指标

论文中所有数值均来自未改动的仿真器步进函数。覆盖率为至少被观测一次的任务单元比例；
冲突率统计间距低于报告阈值的无序飞行器对，并按"对-步"机会数归一化；路径长度累加
欧氏位移。冲突统计以**整数对事件数配精确 Poisson 置信区间**报告，因为在该量级下
单个事件就会让报告值变动约 2.4e-4。

## 论文中的报告约定

论文中有若干**负面结果**被如实报告，而非粉饰：

* 覆盖感知修正目标 CVA-SP 在饱和协议与刻意降低覆盖率的 regime 下**均无可测量的
  覆盖提升**。机制是尺度失配：修正可达范围 82.5 m，而感知足迹半径 612–918 m，
  因此覆盖项在候选之间近乎恒定。
* 在相同训练预算下的单域对照实验达到与多域模型基本相同的覆盖率，因此原先归因于
  "领域多样性"的覆盖提升实为**训练预算效应**。
* 当不存在任何可行修正时，滤波器会原样执行原始动作。这在 151,200 次飞行器-步决策中
  发生 115 次，其中一次连续 33 步，应视为**逐飞行器顺序滤波**的固有局限。
